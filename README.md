## 🚀 快速上手（新手最短路径）

1. 选一个启动器：Windows 中文玩家首选 **PCL2** 或 **HMCL**，跨平台/资深玩家用 **Prism Launcher**（详见 [第 1 章](docs/01-launchers.md)）。
2. 确认 Java 版本：1.17 需 Java 16，1.18–1.20.4 需 Java 17，1.20.5+ 需 Java 21（详见 [第 2 章](docs/02-versions.md)）。
3. 想玩模组：先选**加载器**（1.20.1 选 Forge/NeoForge/Fabric 皆可；1.21+ 主流 NeoForge/Fabric），再按 [第 4 章](docs/04-mods.md) 挑模组。
4. 想省事：直接找整合包（[第 7 章](docs/07-modpacks.md)），启动器内一键导入。
5. 想开服/联机：见 [第 8 章](docs/08-servers-multiplayer.md)。

## 📌 使用约定

- 链接指向各项目**官方站点或主流分发平台**；版本号随上游更新，以平台页面为准。
- 模组之间存在加载器与 Minecraft 版本对应关系，**下载前务必核对游戏版本与加载器**。
- 本库为索引性质，不提供盗版游戏本体；Java 版需通过 [minecraft.net](https://www.minecraft.net) 正版获取。
- 平台全量项目数以十万计，仓库正文为精选清单，全量浏览走顶部速查表与各章入口。
