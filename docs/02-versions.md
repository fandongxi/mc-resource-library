# 2. 版本与 Java 环境

## 2.1 版本体系

- **Java 版**：PC/Mac/Linux，模组生态全部集中于此，本库以 Java 版为主。
- **基岩版 (Bedrock)**：Win10/11、主机、手机，市场内置，模组以行为包/附加包（Add-on）形式存在，生态与 Java 不互通。
- **教育版**：课堂用途，不纳入本库。

### Java 版常见长期支持版本（模组生态密集）

| 版本 | 生态地位 |
| --- | --- |
| 1.12.2 | 老牌内容模组最后的繁荣期（神秘时代、工业 2、格雷科技经典线大量停留在该版） |
| 1.16.5 | 优化模组与魔法模组过渡版，仍有大量整合包维护 |
| 1.18.2 | 世界生成重做后早期稳定版 |
| **1.20.1** | **Forge 末代稳定版 / NeoForge 起点，当前内容模组密度最高的版本之一** |
| 1.21.x | NeoForge / Fabric 主流新版本，模组持续迁入 |

> 版本选择原则：**想玩的模组/整合包停在哪个版本，就用哪个版本**，不要盲目追最新正式版。

## 2.2 Java 运行环境对照（Java 版）

| Minecraft 版本 | 所需 Java |
| --- | --- |
| 1.12.2 及更早 | Java 8 |
| 1.16.5 | Java 8（部分模组需 Java 11） |
| 1.17.x | Java 16 |
| 1.18.x – 1.20.4 | Java 17 |
| 1.20.5 及更高（1.21+） | Java 21 |

- 推荐使用 Adoptium Temurin 发行版：https://adoptium.net （启动器通常可自动下载/配置对应 Java，无需手动安装）。
- 64 位系统必须用 64 位 Java；分配内存与 Java 位数一致。
- 启动器内「自动选择 Java」一般可正确匹配；报错 `UnsupportedClassVersionError` 即 Java 版本不对。

## 2.3 快照 (Snapshot) 与正式版

- 快照为测试版，模组基本不跟，仅用于提前体验新特性，不建议装模组。
- 正式版（Release）才是模组与整合包的目标版本。
- 远古版（1.7.10、1.12.2）玩怀旧包时注意 Java 版本必须降到对应要求。
