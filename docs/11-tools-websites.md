# 11. 实用工具与网站

## 11.1 知识查询

| 站点 | 用途 |
| --- | --- |
| [Minecraft Wiki（中文）](https://zh.minecraft.wiki) | 原版机制、生物、物品、指令权威查询 |
| [MC百科](https://www.mcmod.cn) | 中文模组百科、配方、版本与加载器信息 |
| [Modrinth](https://modrinth.com) | 开源模组/资源包/整合包分发 |
| [CurseForge](https://www.curseforge.com/minecraft) | 最大模组与整合包库 |

## 11.2 启动与运行环境

| 工具 | 用途 |
| --- | --- |
| [Adoptium Temurin](https://adoptium.net) | 免费 OpenJDK 发行版，按第 2 章对照表装对应版本 |
| [PCL2](https://pcl2.org) / [HMCL](https://hmcl.huangyuhui.net) | 启动器，自动准备 Java |

## 11.3 存档与地图工具

| 工具 | 用途 |
| --- | ---
| **NBTExplorer** | 查看/修改存档 NBT 数据（物品、玩家、方块实体） |
| **MCA Selector** | 选区删除/导出区块、修复坏档 |
| **Chunky** | 预渲染/预生成区块，减少多人服卡顿 |
| **WorldEdit** | 服务器/单机创世插件，批量建筑操作 |
| **Amidst / Chunky 地图预览** | 种子结构预览 |

## 11.4 素材与创作

| 工具 | 用途 |
| --- | ---
| [Blockbench](https://blockbench.net) | 免费低多边形模型编辑器，做模组/皮肤/物品模型 |
| [Planet Minecraft](https://www.planetminecraft.com) | 皮肤、材质、建筑、地图作品库 |
| **NameMC**（namemc.com） | 查询玩家名历史、皮肤、斗篷 |
| **Skindex** | 皮肤分享与编辑器 |

## 11.5 服务器与网络

| 工具 | 用途 |
| --- | ---
| [PaperMC](https://papermc.io) / [Purpur](https://purpurmc.org) | 插件服务端 |
| [GeyserMC](https://geysermc.org) | 基岩版桥接 |
| ZeroTier / Tailscale | 虚拟局域网联机 |

## 11.6 国内社区（注意甄别，以官方平台下载为准）

- MCBBS 历史论坛与中文整合包/汉化社区；BBSMC 类镜像站提供整合包与汉化追踪。
- B 站、抖音、贴吧有大量新手教程；下载文件始终回到 Modrinth/CurseForge/启动器内源，不点陌生网盘。
