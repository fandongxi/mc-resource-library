# 12. 教程与学习路径

## 12.1 新手入门（原版）

1. **第一天**：撸树→木板→工作台→木镐→石器→挖煤→熔炉→盖临时庇护所，天黑前上床。
2. **第一周**：找村庄/种田→铁器→附魔台→下矿找钻石→做铁甲。
3. **中期**：下界→烈焰棒→酿造→打末影龙→末地鞘翅。
4. 官方/中文 Wiki 遇到不懂的方块、生物直接搜：https://zh.minecraft.wiki
5. B 站搜「我的世界 新手教程」，选近一两年、与你版本一致的视频。

## 12.2 红石进阶

- 基础：红石粉、火把、中继器、比较器、活塞、观察者。
- 逐级练：自动门 → 刷石机 → 农田收割机 → 分类仓库 → 高频/计算器。
- 资源：中文 Wiki 红石电路条目、B 站红石 UP 主系列；先懂「充能/强充能弱充能」再做装置。

## 12.3 模组玩家路径

1. 先原版通关一遍，理解基础机制再进模组包。
2. 从**轻量整合包**（30–80 模组）上手，再碰厨房水槽大包，最后挑战专家包（GTNH 类）。
3. 每个新机器先看 JEI 配方与包内任务书，不要堆机器不管流程。
4. 崩溃排查：启动器崩溃报告 → 找最后一个 `Caused by` → 对照 MC百科/Modrinth 页面查缺前置或冲突。

## 12.4 服务器搭建学习

1. 先本地开一个 Paper 测试服（见 [第 8 章](08-servers-multiplayer.md)）。
2. 装 1–2 个插件理解 `plugins/` 与 `config` 结构。
3. 再试模组服，理解服务端/客户端 mods 一致性。
4. Paper 官方文档：https://docs.papermc.io ；Fabric 中文文档：https://docs.fabricmc.net/zh_cn/

## 12.5 模组开发（进阶）

- **Fabric**：官方文档 https://docs.fabricmc.net/zh_cn/ ，门槛低、文档友好，推荐入门。
- **NeoForge**：官方文档 https://docs.neoforged.net ，承接 Forge 生态。
- 前置知识：Java 基础、Gradle 构建、Mixin/事件系统概念。
- 先从「添加一个物品/一个方块」的 Hello Mod 模板起步。

## 12.6 学习习惯建议

- 建世界练习前**先备份**（复制存档文件夹）。
- 遇到问题先查 Wiki / MC百科，再看崩溃日志，最后才问人。
- 版本认准，视频教程与你游戏版本差太多时，菜单名称与机制可能不同。
