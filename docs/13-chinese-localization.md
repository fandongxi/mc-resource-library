# 13. 汉化资源

> 本章收录汉化获取途径与通用导入方法；**汉化补丁版权归原译者**，请通过社区合规渠道获取，不附网盘链接。

## 13.1 汉化来源

| 来源 | 说明 |
| --- | ---
| **MC百科**（https://www.mcmod.cn） | 多数模组页面附中文介绍与汉化线索，可查模组中文名 |
| **中文整合包社区 / 汉化追踪** | 大型整合包（ATM、FTB 等）常由社区发布配套汉化包，随包版本更新 |
| **启动器内置汉化** | PCL2 整合包市场部分条目附带汉化或汉化入口 |
| **Modrinth / CurseForge** | 部分模组自带 `zh_cn` 语言文件，无需额外补丁 |
| **MCBBS 系历史论坛与镜像站** | 中文模组翻译存档集中地，注意甄别文件安全 |

## 13.2 汉化包通用导入方法

### 方式一：覆盖语言文件（传统汉化补丁）

1. 打开版本文件夹：启动器「版本设置 → 打开版本目录」，进入 `mods` 同级或对应 `.minecraft` 目录。
2. 解压汉化压缩包，按说明把文件覆盖到 `config` / 资源包 / 模组语言目录。
3. 多数汉化补丁是**资源包形式**：把压缩包直接放入 `resourcepacks/`，游戏内启用即可。
4. 进入游戏「选项 → 语言」切到「简体中文」。

### 方式二：模组内自带汉化

- 确认模组为较新版本，游戏语言设为简体中文后自动生效；缺失词条会回退英文，属正常。

## 13.3 常见问题

| 问题 | 处理 |
| --- | --- |
| 汉化后部分物品仍是英文 | 该词条译者未翻译，属正常；换更新版本的汉化包 |
| 覆盖后游戏崩溃/物品乱码 | 汉化包与游戏版本不匹配，删回该汉化文件，换对应版本 |
| 整合包升级后汉化失效 | 汉化包版本需与包版本严格对应，升级后找新版汉化 |
| 菜单变方块/问号 | 缺少中文字体或资源包未启用，检查资源包优先级 |

## 13.4 自己翻译（贡献汉化）

- 模组语言文件为 `assets/<modid>/lang/zh_cn.json`，对照 `en_us.json` 翻译键值即可。
- 提交前在游戏内逐界面核对，避免长文本撑爆 UI。
