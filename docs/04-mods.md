## 4.0 全量入口（想翻遍全部模组从这里进）

| 平台 | 全部模组入口 | 说明 |
| --- | --- | --- |
| **Modrinth** | https://modrinth.com/mods | 开源友好、更新快，可按版本/加载器/分类筛选，搜索直达 |
| **CurseForge** | https://www.curseforge.com/minecraft/mc-mods | 项目库最大（34 万+），老牌内容模组齐全 |
| **MC百科（中文）** | https://www.mcmod.cn | 中文介绍、配方、版本与加载器对照 |

> 用法：在平台顶部搜索框输入模组名，或按 Categories（Tech / Magic / Adventure…）筛选；先核对 **Minecraft 版本 + 加载器**。
> 下表「搜索」列为 Modrinth 搜索直达；CurseForge 同名项目在其站内搜即可。

## 4.10 挑选原则

1. 先定版本与加载器，再按平台分类筛选。
2. 看下载量、更新时间、评分；冷门模组先确认仍在维护。
3. 补齐前置依赖；同功能模组（多个小地图/优化）避免重复。
4. 平台「全部入口」见 4.0，全量项目数以十万计，本表为精选。
