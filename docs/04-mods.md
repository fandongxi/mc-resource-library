## 4.7 如何挑模组

1. 先定游戏版本与加载器，再在平台按分类筛选。
2. 看**下载量、更新时间、评分**；冷门模组先看是否仍在维护。
3. 注意前置依赖（JEI、Architectury API 等），缺前置会崩。
4. 同功能模组（多个小地图、多个优化）避免重复安装，防止冲突。
5. 模组顺序一般不影响加载（Forge 除外的特殊依赖顺序以包作者说明为准）。
