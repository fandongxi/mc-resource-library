# 1. 启动器 Launchers

启动器负责下载游戏本体、管理多版本、安装加载器/模组、配置 Java 与内存。
**正版账号均可登录**；离线模式仅用于单人/本地，联机服务器以服务器要求为准。

## 1.1 主流启动器对比

| 启动器 | 平台 | 加载器支持 | 特点 | 获取 |
| --- | --- | --- | --- | --- |
| **PCL2** (Plain Craft Launcher 2) | Windows | Forge / NeoForge / Fabric / Quilt / OptiFine | 中文玩家首选；版本隔离、整合包一键导入、崩溃分析、内置资源社区、汉化方便 | https://pcl2.org |
| **HMCL** (Hello Minecraft! Launcher) | Win / Linux / macOS | Forge / NeoForge / Fabric / Quilt / LiteLoader / OptiFine | GPLv3 开源、跨平台、JVM 参数预设完善，资深模组玩家常用 | https://hmcl.huangyuhui.net |
| **BakaXL** | Win / macOS / Linux | Fabric / Forge 等 | 4.0 跨平台、界面个性化程度高、轻量流畅 | https://www.bakaxl.com |
| **Prism Launcher** | Win / macOS / Linux | 全主流加载器，深度对接 Modrinth/CurseForge | 开源、实例（Instance）管理强、可直接从平台安装更新模组，欧美社区主流 | https://prismlauncher.org |
| **官方启动器 (Minecraft Launcher)** | Win / macOS | 仅原版 / OptiFine（手动） | Mojang 官方，更新最及时，模组管理需手动 | https://www.minecraft.net/download |
| **ATLauncher** | Win / macOS / Linux | Forge / Fabric / NeoForge | 自带整合包仓库，可视化模组勾选组装整合包 | https://atlauncher.com |
| **MultiMC** | Win / Linux / macOS | 全主流 | Prism 的前身，实例管理思路经典 | https://multimc.org |

## 1.2 选型建议

- **Windows 新手 / 中文玩家**：PCL2，内置整合包与汉化追踪，门槛最低。
- **想要开源放心 / Mac/Linux**：HMCL 或 Prism Launcher。
- **大量实例并行、追求模组在线管理**：Prism Launcher。
- **只想玩原版**：官方启动器即可。

## 1.3 通用注意事项

1. 游戏目录建议放在**纯英文路径**，避免中文/特殊符号导致模组或脚本异常。
2. 每个版本独立目录（版本隔离），模组冲突时便于回滚。
3. 分配内存建议：原版 2–4 GB；轻量模组包 4–6 GB；大型整合包 6–10 GB（不要超过物理内存的 70%）。
4. 下载游戏与模组时优先使用启动器内置源；国内网络可在启动器设置中切换镜像源。
