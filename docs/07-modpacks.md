# 7. 整合包 Modpacks

整合包 = 作者已经配好加载器+模组+配置+任务线，玩家导入即玩，**新手最省事的路径**。

## 7.1 分发平台

| 平台 | 说明 |
| --- | ---
| **CurseForge** | 整合包项目最多，官网 https://www.curseforge.com/minecraft/modpacks |
| **Modrinth** | 开源友好，https://modrinth.com/modpacks |
| **ATLauncher / FTB App** | 客户端内直接浏览安装 |
| **PCL2 / HMCL** | 内置整合包市场，支持 `.mrpack` 与 CurseForge 包直接拖入导入 |

## 7.3 导入方法（PCL2 为例）

1. 下载整合包文件：CurseForge 包为 `.zip`，Modrinth 标准包为 `.mrpack`。
2. 启动器「整合包」页面 → 直接拖入文件 → 等待自动安装依赖。
3. 内存按包说明分配（大包建议 6–10 GB）。
4. 汉化补丁见 [第 13 章](13-chinese-localization.md)。

## 7.4 注意事项

- 整合包锁定版本与加载器，**不要自行增删模组**，易破坏任务线与配方平衡。
- 大包首次启动需要加载资源，耐心等待，崩溃先看启动器崩溃报告。
- 存档与包版本绑定，升级包版本前备份存档。
